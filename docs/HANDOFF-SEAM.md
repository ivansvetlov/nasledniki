## Контракт UI (как должно)

**Красные.** ПКМ по границе → якорь на ребро. Вторая на том же шве примагничивается к **тому же телу**, что первая. Соседние = между ними по контуру нет другой красной. ПКМ по точке удаляет.

**Зона.** Строго короткая дуга между двумя соседними красными. Нет двух красных / клик не на дуге → не гнём.

**Жёлтая.** ЛКМ-тяга между парой. Живёт на теле красных: это тело растёт, сосед худеет.

**Нельзя.** Воду не пишем. Внешний край не изобретает полуостров. Тройник на концах зоны не едет. Нельзя красными захватить дугу **через** тройник (`walkHasJunction` — отказ: «красные до узла и после»).

**Спрямление.** Жёлтая на прямой между двумя красными → дуга снова **отрезок** (самый короткий). Иначе петли.

**5px.** На открытой дуге пол ≥ 5px. У якорей, особенно на тройнике (бывает 2.9px), щель **плавно сходит** к исходной (`blend01`). Требование «ровно 5px в прибитой точке тройника» снято — физически нельзя.

## Текущая реализация (канон кода)

`deform_pair` / `deformPair` **не** тащит текущую ломаную и **не** параболу-контроль.

Каждый кадр:

1. Квадратичная, **проходящая через** S, жёлтую, E (`interpolating_quadratic`). Жёлтая на хорде S–E → хорда.
2. Сосед: `offset_open` на `SEAM_GAP=5` к центроиду B.
3. Концы B прибиты к ближайшим точкам исходного B (`sb`,`eb`), середина — офсет, у якорей blend к `sb–eb`.
4. `replace_facing_arc` в оба кольца. Если `iS==iE` (одно ребро): `around` = длинный обход тела; при неверном знаке площади **реверс всего контура**, не `around`.
5. `_clamp_ring_gap` / `clampRingGap` только дальше **8px** от S/E.

Жёлтая на экране после кадра сажается на кромку растущего тела (`yellowOnGrowBody`).

Вода: `hitsWater` на новых дугах → кадр не пишется (коллайдер).

## Что пробовали и почему сняли

| Подход | Почему нет |
|---|---|
| Карандаш excursion | Нет объёма, 5px не держится как жест |
| Автокоридор 10px + «тройники» | Гнулся весь шов, не две красные |
| Жёлтая = ближайшее тело под курсором | На щели 5px ближайший — сосед |
| Парабола как control (не через Y) | Линза; тройник `200,329` / `202,328` |
| Сдвиг существующих вершин + offset | Длина дуги растёт; обратный жест **скручивает петли** |
| Общий CAD-сплайн на всю карту | Стартовые швы 3–10px, два независимых OSM-контура |
| MLS / Paper.js | Оверкилл: одна жёлтая, два якоря |

Gemini (`Desktop\глм предложение.txt`): взять **виртуальную середину ±2.5**, ресэмпл вместо OSM-зубцов, taper у якорей, запрет тройника внутри, вода-коллайдер. Не брать общий сплайн как канон и не MLS. Код сейчас ближе к «S–Y–E = берег A, B = offset 5px», не к чистой midline (функции `build_midline` / `buildMidline` ещё лежат, `deform_pair` их не зовёт).
