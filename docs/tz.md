«НаСЛЕДНИКИ» — это экспедиции, в которых ребенок становится участником исследования своего края.

Во время каждой поездки ребенок:

* открывает новые места;
* знакомится с историей региона;
* встречается с интересными людьми;
* выполняет исследовательские задания;
* работает в команде;
* создает собственную историю путешествий.

Главная идея:

Не просто посмотреть место. Открыть его.

**13. ЛИЧНЫЙ КАБИНЕТ НАСЛЕДНИКА**

**(Регистрация участника до первой экспедиции)**

**Общая идея**

Личный кабинет создается для каждого участника до начала первой поездки.

Регистрация является обязательным этапом записи ребенка на экспедицию.

Через личный кабинет:

* собираются данные участника;
* оформляется участие;
* хранится история поездок;
* ведется журнал Наследника;
* начисляются достижения.

**ЭТАП 1. СОЗДАНИЕ ПРОФИЛЯ УЧАСТНИКА**

**Регистрация проходит через родителя.**

Родитель создает аккаунт и добавляет ребенка.

**Данные родителя:**

Обязательные поля:

* ФИО родителя/законного представителя;
* номер телефона;
* электронная почта;
* мессенджер для связи

**Данные ребенка:**

Обязательные поля:

* ФИО ребенка полностью;
* дата рождения;
* возраст;
* школа;
* класс;
* город проживания;
* контактный телефон ребенка (если есть).

**ДАННЫЕ ДОКУМЕНТА РЕБЕНКА**

Так как часть экспедиций включает посещение режимных объектов, необходимо заранее собирать данные документов.

**Поля:**

Выбор документа:

○ Свидетельство о рождении
○ Паспорт ребенка

Далее:

* серия документа;
* номер документа;
* дата выдачи;
* кем выдан (при необходимости).

**Зачем это нужно:**

Данные используются для формирования списков участников для посещения объектов с пропускным режимом.

Например:

* СВВАУЛ;
* Транспорт будущего;
* специальные площадки партнеров.
* Справка в ГИБДД

**ВАЖНО:**

Необходимо предусмотреть:

* защищенное хранение персональных данных;
* доступ к документам только администратора;
* возможность выгрузки списка участников в формате Excel/PDF;
* возможность фильтрации по конкретной экспедиции.
