## Топ-приёмы для детской экспедиционной карты (сводка)

1. **SVG-карта области + кликабельные районы с бейджами** (Ruralitud). Один инлайн-SVG Самарской области, районы = `<path>`, на каждом число экспедиций. Клик фильтрует список карточек. Просто, быстро, без API.
2. **Пины-иконки по категориям + hover-тултип** (Ayla). Гора/река/музей/лагерь = своя иконка, на hover тултип с «хвостиком».
3. **Master-detail: список ↔ карта по координатам** (Nesma). Hover карточки экспедиции подсвечивает точку на карте; карта «приклеена» при скролле.
4. **Мультифильтр: регион + категория + поиск + сброс** (GGE). «Только пешие», «по Волге», счётчик «показано N из M».
5. **Игровые слои: этапы + трейлы-маршруты** (Ayla/San Rita). «Этап 1/2/3», линии трейлов, тумблер «Показать маршрут».

## Топ-приёмы графики поверх карты

1. **«Старт-путешествия»** (Planetono «StArt», Primland «Explore the map») — экран-дверь с кнопкой «В путь!» + тематический прелоадер «Собираем рюкзаки… 20%» (San Rita).
2. **3D-мир = фикс. сцена под скроллом** (Planetono степпер, Primland fixed-canvas) — карта Самарской области в кадре, секции пролетают поверх.
3. **Легенда-слои и тумблеры** (San Rita) — «Показать тропы», «Где живут животные», «Маршрут дня».
4. **Живая природа + сезоны** (Primland) — птицы по путям, облака, туман, смена лето/осень/зима.
5. **Переходы-«порталы» между локациями** (Primland/San Rita) — «провал» в конкретное место с новым кадром камеры.

## Топ-приёмы мультяшной детской графики

1. **Секции-«облака»** с гигантскими скруглениями (Persona) — страница течёт «волнами-холмами», как ландшафт области.
2. **Сквозной маскот + персонажи-помощники** (Persona) — PNG/SVG с прозрачностью, въезжают с пружинным bounce.
3. **Мягкие кнопки-капсулы + трекер-свечение** (Persona + Consolidator) — неоморфизм + неоновый след за курсором.
4. **Уровневые вкладки** (Persona) — 10-12 / 13-15 / 16-17 открывают выезжающие панели.
5. **Микроанимации**: покадровый текст по буквам, маркиза локаций, счётчики (км/экспедиции).

## Рекомендуемый стек (из референсов, проверенный рецепт «вау»)

Плюс наш бенч (173 живых паттерна HTML/CSS/JS) для лёгких элементов.

## Решение по карте (отвечает на вопрос из ТЗ)

**Берём реальные геоданные (GeoJSON границ Самарской области из OpenStreetMap) → отрисовываем поверх стилизованный SVG-контур** (плавный, фирменный), Волга — лента, города — анимированные маркеры, маршруты — пунктир. Наслаиваем «экспедиционный журнал»: штриховка, штампы, компас, hover-показы (дата/монеты/задания из ТЗ про карту открытий). Это даёт и достоверность формы, и полную свободу стилизации.

### Первый шаг реализации
- Скачать GeoJSON границ Самарской области + координаты 4 городов (OSM).
- Сгенерировать стилизованный SVG (плавные контуры, Волга, маркеры).
- Собрать прототип карты: клики по городам, hover-тултипы, анимация маршрутов, бейджи (в духе Ruralitud/Ayla).
