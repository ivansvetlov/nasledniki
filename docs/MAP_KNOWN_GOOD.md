## Инварианты (проверяются скриптом)
Скрипт: `scripts/verify_map_good.py` → `python scripts/verify_map_good.py`
Должен печатать `РЕЗУЛЬТАТ: PASS` (exit 0). Запускать ПЕРЕД тем, как считать
любую правку карты/редактора завершённой.

- G1. Слой `id=1` «Районы» — ровно 26 районов, набор имён == эталону.
- G2. Слой `id=3` «Волга» (water-overlay): ровно 3 тела — Волга + Куйбышевское +
  Саратовское водохранилища.
- G3. Путь «Волга»: `fill="#B7C4BC" fill-opacity="0.5"`, геометрия без кривых `C`
  (чистый полигон). БЕЗ заливки путь рисуется ЧЁРНЫМ — этого быть не должно.
- G4. Геометрия не искажена сплайном: пути районов не содержат `C`; суммарно `C`
  в файле < 50 (эталон 7).
- G5. Подсистема сплайнизации ОТКЛЮЧЕНА в `scripts/map_editor.js` (guard-ы
  «сплайнизация отключена» в `materializeSplines` и «SPLINE DISABLED» в
  `renderDistrictSide` на месте).
- G6. `state.json` (если есть) не противоречит SVG: водный слой `id == 3`.

## Перебазировка эталона (когда карту меняют легально)
Инварианты самобазируемые: ожидаемые значения (набор имён районов/воды, заливка
Волги) берутся из `map.svg.good`, а не захардкожены в скрипте. Поэтому легальное
изменение карты требует только обновить эталон:

1. Внести правку в `map.svg` (в редакторе или руками).
2. Визуально проверить результат в браузере (Волга на месте, геометрия цела).
3. Скопировать: `map.svg` → `map.svg.good` (и при необходимости `state.json` → `state.json.good`).
4. `python scripts/verify_map_good.py` → должен быть `PASS`.
5. Закоммитить ВМЕСТЕ `map.svg` и `map.svg.good` одним коммитом.

## Автоматический гейт (pre-commit hook)
В репо есть `hooks/pre-commit`, который блокирует коммит, если ломаются инварианты
карты (при изменении `map.svg` / `map_editor.js` / `verify_map_good.py` / `*.good`).
Активация — один раз локально: `git config core.hooksPath hooks`.
При блокировке исправь карту или перебазируй эталон, затем коммить снова.

## ЖЁСТКИЕ ПРАВИЛА для будущих итераций
1. **`map.svg` — источник истины по геометрии.** `state.json` — перегенерируемый
   кэш топологии (его перезаписывает редактор при загрузке/сохранении). Если
   `state.json` рассинхронизирован по `id` слоёв с `map.svg` — удали `state.json`,
   редактор пересоберёт его из SVG. Не правь карту ТОЛЬКО через `state.json`.
2. **Не удаляй и не переименовывай Волгу.** Водный слой должен оставаться
   `data-layer-id="3" data-layer-name="Волга"`, путь Волги — с `fill="#B7C4BC"`.
3. **Сплайнизация намеренно отключена, но код НЕ удаляем — дорабатываем.**
   Кнопка «сделать сплайн» / `materializeSplines` ломает геометрию ВСЕХ районов
   (путь района сжимается ~в 10 раз, L→C), а undo её не откатывает, т.к. `topoSnapshot`
   хранит только контрольные точки сплайна, а не исходный `d`. История топо не
   переживает перезагрузку (`compact()` и фильтр загрузки режут `type:"topo"`).
   План: подсистему **исправить** (хранить исходный `d`, чинить `renderDistrictSide`,
   сохранять топо-историю при перезагрузке), а не выпиливать. Пока guard-ы
   (`materializeSplines`, `renderDistrictSide`) остаются — чекер G5 следит, чтобы их
   не убрали случайно.
4. **Редактор грузится по URL `/prototype/map-bench.html`** (НЕ `/index.html`),
   авторизация Ivan / Svetlov10!, затем `openMap('samara')`.
