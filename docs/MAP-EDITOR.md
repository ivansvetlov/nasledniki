# Карта районов — что зафиксировано (2026-08-20)

## Зачем это всё (и куда уехали)

Продукт из ТЗ — сайт экспедиций **«НаСЛЕДНИКИ»** (дети 10–17, Самарская область,
ООО «Кинокомпания Медиа-С»). Не лендинг продаж, а платформа: заявки, кабинет
ребёнка, журнал, монеты, викторина, **карта путешествий**.

Карта в ТЗ — не «редактор как Figma». Это:

1. **«Моя карта путешествий»** в кабинете: Самара / Сызрань / Тольятти / Жигулёвск
   как открытые и серые точки, «можно визуализировать как карту региона».
2. Визуальный язык (NatGeo, блокноты, бумажная карта) — фото детей почти нельзя,
   значит география и локации несут картинку.
3. Чтобы это не рисовать вручную в Paint: **политическая карта районов** как
   SVG-актив — 27 тел, щель = подложка `#F2E8D5`, без stroke, округа влиты
   в район. Самара — канон нарезки.

Редактор вырос как **мастерская актива**, не как сайт. Шов, якоря, карандаш,
слои, проекты, аккаунт, загрузка Петербурга — чтобы править геометрию и не
терять работу. Это ок, пока мастерская устраивает. Но сайт (заявки, кабинет,
журнал, карта открытий на проде) **ещё не начат**. Не путать инструмент
с продуктом.

| Это продукт сайта | Это мастерская карты |
|---|---|
| 27 районов Самары как SVG, стиль щели | карандаш / шов (якоря) / линейка |
| округа → родитель (Тольятти в Ставропольский…) | слои, текст, ПКМ, журнал отмены |
| кликабельные `<path>` без обводки | проекты, аккаунт Ivan, автосейв |
| | загрузка области/города из OSM (ЛО, СПб) |

Как натянуть стиль сайта на геометрию цеха — `docs/MAP-ARCH.md`.
Работает: `GET /v1/maps/samara/geometry`, темы `/v1/themes`, витрина
`http://127.0.0.1:8765/nasedniki/map` (`nasedniki-flow` = сильное обтекание).

Дальше по продукту: вшить карту Самары в кабинет «открыл район / город»,
не наращивать редактор, пока не упрёмся в шов или новый субъект.

## Проекты

Слева рельс **Проекты**. Текущий открытый — с синей точкой; под ним сворачиваются
**Слои** и **Журнал** (как история). **+** — новый пустой
проект (бежевый холст, слои, инструменты). В карточке проекта поле поиска: вводишь «Санкт-Петербург» — крутится загрузка,
в проект садится город (одно тело). Область по-прежнему даёт районы.

Двойной клик по имени — переименовать. ПКМ по карточке — переименовать / удалить.
Прибрежные карты (СПб) после загрузки: слой **Вода** (Нева, Финский залив) под районами.
Кнопка **загрузить** сажает поиск в *текущий* проект; список проектов кликается и во время загрузки.

```
+ проект  →  пустой холст maps/<slug>/
в проекте →  поиск («Тольятти», «Санкт-Петербург», «Ленинградская область»)
          →  Nominatim + zone_rel_ids (см. регламент ниже)
          →  map.svg в папке проекта
```

### Правила нарезки OSM (регламент)

Это не «как получится у Overpass», а контракт загрузки:

| Что ищешь | Что должно появиться на холсте |
|---|---|
| **Область / край / республика** | муниципалитеты `admin_level=6` (районы и городские округа области). Городские округа **вливаются** в родительский район (как Тольятти → Ставропольский). |
| **Федеральный город внутри области** | **отдельное тело**, не район области. СПб не входит в admin 6 Ленобласти, Москва — не в МО. Их дописываем по таблице: ЛО `176095` → СПб `337422`; МО `51490` → Москва `102269`. |
| **Санкт-Петербург / Москва / Севастополь как запрос** | районы субъекта (`admin_level=5`). Если их нет или кусков больше 36 — **одно** городское пятно, не 100+ муниципальных округов. |
| **Один район / городской округ** | одно тело. |
| **Вода** | OSM уже держит воду отдельно от районов. Площади: `natural=water` (озеро, пруд, река-полигон), `waterway=riverbank` (старый берег реки), `natural=bay` / `place=sea` (губа, залив). Не центрлинии `waterway=river` и не «всё, что не суша». Берём объекты, пересекающие кадр; **обрезаем рамкой** (море целиком не тащим и не выкидываем). Имя как в OSM. Безымянная река → «река». Безымянная лужа — выкидываем. Слой **Вода** под районами; вода вырезается из районов, если кадастр залез на воду. Overpass молчит → слой пустой, не выдумываем. |
| Overpass 502 / таймаут | не молча «клякса без районов», если знаем фед. город: контур области **плюс** город. Если и этого нет — одно тело и в лог `overpass лёг`. |

Почему ЛО без Петербурга: OSM считает СПб **отдельным субъектом**, не муниципалитетом Ленобласти. Без регламента пайплайн честно выкидывал «прочие» геометрии. Теперь прочие федеральные города остаются отдельным path.

## Модель данных редактора

Два канона одновременно:

1. **SVG path** — то, что видит человек. Вершины берегов не пересчитывать с растра
   при объединении.
2. **Растр `labels[y*W+x]`** (Uint16) — канон для ножа/ластика. 0 = подложка.
   Карандаш считает границу векторно (`scripts/pen_geom.py` / `extractExcursion` в `map_editor.js`).

При **объединении** правим path векторно (сшивка контуров по шву) и те же пиксели
зазора пишем в `labels`. Нельзя после merge вызывать полный `rebuildIds` по маске —
это заново обводит **всё** тело (Волга, дальние края «плывут»).

Карандаш/нож по-прежнему перетрассируют только задетые id.

## Объединение (шов)

Смысл: два соседних тела становятся одним. Зазор между **этой парой** становится
телом. Чужие щели, вода и третьи районы не трогаем. Лишней площади нет.

### Когда соседи

Общая тонкая щель (не «рядом через Волгу»). Дилатация 28 px / морфологическое
закрытие всего тела — **запрещены**: дают мост через воду (Ставропольский×Шигонский)
или подъедают щели к третьим (Красноармейский×Пестравский).

### Как ищется шов

`scripts/pair_geom.py` + тот же алгоритм в `map_editor.js`:

1. Уплотнить контур шагом 2 px.
2. Точка «на шве», если расстояние до соседа ≤ `FACE_MAX` (7 px).
3. Короткие провалы, где расстояние всё ещё ≤ `FACE_MAX+FACE_SLACK` (10 px),
   склеивать (`FACE_HOLE` до 80 вершин). Иначе шов обрывается на изгибе
   5.02 px (Красноярский×Сергиевский: ложный конец `465,295` вместо `498,303`;
   Кинель-Черкасский×Кинельский: обрыв ~`530,392` вместо ~`549,414`).
4. На каждом **конце** шва короче тот край, который раньше кончается: с него
   нормаль на соседа (пример Приволжский `206,399` → Сызранский ~`207,396`;
   Сызранский `112,468` → Приволжский ~`116,467`).
5. Сшивка: обход **длинной** стороны каждого исходного контура + две нормали.
   Вершины не-шва не переписывать. `fill-rule: nonzero`.
6. Пиксели зазора внутри полоски шва → id оставляемого района.
7. Если после записи площадь выросла не зазором — откат.

Не делать: два полных контура + полоска с `evenodd` (полоска перекрывает тела →
дыры). Не делать Chaikin «для красоты» на гранях (откатили).

Волга (~15 px) не шов. Не поднимать `FACE_MAX` к 15.

## Инструменты редактора

| Действие | Как |
|---|---|
| Выбор | клик по району / слою. Повторный клик по выбранному — снять. Esc. Клик по подложке |
| Мультивыбор | Shift+клик. ПКМ внутри тела → объединить, только если тела на одном слое |
| Шов | ПКМ по границе — красная. Зона — строго дуга между двумя соседними красными по границе; ЛКМ между ними — жёлтая на **том же теле**, что красные (это тело растёт, сосед худеет, щель 5px). Без двух красных не гнём. ПКМ по точке — удалить. Внешний край и воду не тянем. Esc — отмена тяги |
| Карандаш | пока остаётся как отдельный режим P. Шов правим якорями, не карандашом |
| Линейка | `R`. Клик — первая точка; пунктир бежит за мышью с текущей длиной; второй клик — фиксация. Тонкая пунктирная линия. Магнит к кромке (второй конец — чужое тело). Alt — без магнита. Esc — сбросить |
| Объединить | ПКМ по выбранным (или `M`). Только соседи с общей щелью и **на одном слое**. Тела на разных слоях — пункт серый, сшить нельзя |
| Рука | **второе** нажатие (не отпускать) — тащить; отпустил — указатель. Не залипает. Space/Alt/средняя — как раньше |
| Крестик | координаты SVG `x × y` и имя под курсором |
| Отмена | Ctrl+Z / Ctrl+Y — любая раскладка (`KeyZ`/`KeyY`). Журнал внизу слоёв: свернуть/развернуть, клик по записи — откатить сюда (серые — повтор) |
| Слои | один тип слоя. `+` — новый слой. ПКМ по телу — на любой существующий слой или новый. Текст на любом слое: `T` затем клик, или ПКМ «вставить текст». Двойной клик по тексту — правка, перетащить, ПКМ — на другой слой / удалить |
| Проекты | рельс **Проекты**. Текущий выделен. **+** — пустой проект. В проекте — загрузить район/город/область из OSM |

## Что пробовали и отвергли

| Попытка | Почему нет |
|---|---|
| Stroke `#2B2317` поверх заливок | чёрное внутри тел; щель должна быть подложкой |
| Трассировка всех светлых пикселей JPG как одного blob | нет районов |
| Paint как обязательный шаг | контракт: JPG/OSM → SVG без рук |
| Карандаш перетрассирует все path с canvas | эрозия соседей |
| Merge = перекраска без заливки щели | vis-union, не одно тело |
| `evenodd` дырки из всех внутренних нулей | фантомные дыры в теле |
| `closeKeepGaps(r=28)` / dilate 28∩dilate 28 | мост через Волгу, щели к третьим сжимаются |
| `foreignDilate(28)` | шов не доливается (Исаклинский и др.) |
| Chaikin согласованно по граням Сызранского | «уродски», откат SVG из OSM заново |
| Два path + полоска шва, `evenodd` | дырявая заливка, «очень поломалось» |
| Ждать 280 мс «не двойной ли клик» | лаг выбора зоны |

## Открытые задачи

- Политика эксклава Кинель-Черкасского (check-map FAIL ×2).
- Волжский южный язык vs Безенчук — правка зонирования в редакторе, не сглаживание.
- Глобальное сглаживание OSM под «атлас» — только если снова решим; не Chaikin вслепую.
- Нож всё ещё перетрассирует задетый район с растра (зубцы на шве после реза).
- Выравнивание границ (ползунки + превью) — этап B, не карандаш.
- `prototype/map.html` живёт отдельно (экспедиции, 4 зоны).
