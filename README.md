# «НаСЛЕДНИКИ» — экспедиционный сайт для детей

Познавательно-экспедиционный проект для детей и подростков 10–17 лет.
Самарская область. Организатор: ООО «Кинокомпания Медиа-С».

## Документы

- `docs\tz.md` — исходное ТЗ (markdown, из .docx)
- `docs\tz-original.docx` — оригинал ТЗ
- `docs\ANALYSIS.md` — разбор слабых мест, улучшения, стек, план, список арт-работ
- `docs\MAP-PIPELINE.md` — контракт стиля: заливки, без stroke, без Paint
- `docs\MAP-EDITOR.md` — OSM-геометрия, редактор, шов, что не повторять (2026-08-20)
- `docs\MAP-ARCH.md` — как цех отдаёт геометрию сайту: темы, вырезка зон, publish API
- `docs\OSM-QGIS.md` — 37 единиц admin_level=6, округа → районы

## Статус

**Продукт** — сайт «НаСЛЕДНИКИ» (ТЗ: экспедиции, кабинет, журнал, карта
путешествий по Самарской области). Сайт не собран.

**Сделано** — мастерская политической карты: SVG 27 районов Самары (щель =
`#F2E8D5`, без stroke, округа влиты), редактор шва, загрузка другого субъекта
из OSM, локальный аккаунт (проекты не пропадают после F5). Зачем и где граница
мастерская/продукт — в начале `docs/MAP-EDITOR.md`.

Открывать редактор `http://127.0.0.1:8765/prototype/map-bench.html`.
Карта сайта с темами: `http://127.0.0.1:8765/nasedniki/map` (геометрия из
`/v1/maps/samara`, стиль `nasedniki-flow` / `journal`).
(`python scripts/map_server.py`). Аккаунт **Ivan** уже видит Самару и ЛО.
Сайт целиком: ТЗ разобрано в `docs/ANALYSIS.md`, ждать решений по бюджету/арт/стеку.

## Стек (предложение)

FastAPI + PostgreSQL + Redis/RQ · React/TS + Vite · Three.js/GSAP · Telegram/SMS/email.
